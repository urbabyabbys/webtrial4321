# 🎨 Cheishar Abdil Adzani - Personal Portfolio

Website portofolio interaktif dan modern yang dibangun dengan gaya desain **Claymorphism**, dilengkapi dengan interaksi kursor dinamis, animasi Canvas Matrix, dan kartu lanyard interaktif.

---

## ✨ Fitur Utama

- **Claymorphism UI Aesthetic**: Desain visual 3D neumorphism/claymorphism yang lembut dengan palet warna tosca & pastel yang elegan.
- **Dynamic Character Tracking**: Karakter di halaman beranda secara cerdas mengikuti arah kursor mouse (9 arah tatapan: tengah, atas, bawah, kiri, kanan, dan diagonal).
- **Matrix Canvas Rain**: Animasi angka matrix halus dan transparan pada background canvas.
- **Draggable Lanyard Card**: Kartu ID lanyard interaktif di bagian *About* yang dapat ditarik dan berayun dengan efek fisika pendulum elastis.
- **Typing Text Animation**: Efek mesin tik otomatis saat section *About* terlihat di layar.
- **Project Slider & Modal**: Navigasi slider kartu portofolio dan popup modal untuk melihat detail proyek.
- **Responsive Layout**: Tampilan yang menyesuaikan dengan baik di perangkat desktop, tablet, maupun smartphone.

## 🌐 Cara Mengaktifkan GitHub Pages (Hosting Gratis)

Setelah repository ini di-upload ke GitHub:
1. Buka repository Anda di GitHub.
2. Klik tab **Settings** di bagian atas.
3. Pada menu sebelah kiri, pilih **Pages**.
4. Di bagian **Build and deployment** > **Source**, pilih **Deploy from a branch**.
5. Di bagian **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu 1–2 menit, website Anda akan langsung aktif di URL:
   `https://<username>.github.io/<nama-repo>/`
